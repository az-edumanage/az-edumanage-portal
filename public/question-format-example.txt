Rules
- Questions start with Q : or q : and end with ?.
- Arabic questions can start with س : and end with ؟.
- Multiple choice, short answer, and essay answers start with -.
- Correct answers start with correct, before the answer text.
- True / False questions stay on one line and end with , true or , false.
